## Commands

- `npm start` — start the Expo dev server (Metro). Press `i`/`a`/`w` in the terminal, or use the targeted scripts below.
- `npm run ios` / `npm run android` / `npm run web` — start the dev server and open the app in a specific target.
- `npm run lint` — run ESLint via `expo lint` (flat config in `eslint.config.js`, extends `eslint-config-expo`).
- `npm run reset-project` — one-way scaffolding reset: moves `app/`, `components/`, `hooks/`, `constants/`, `scripts/` to `app-example/` and regenerates a blank `app/`. Only run this if the user explicitly asks to blank out the starter template.
- Pool-steering control's Phase 0 pipeline (dev-only, not shipped in the app) — three steps, run in order: `npm run seed-genres` (fetches + resolves Last.fm data into `assets/genres-raw.json`, needs `EXPO_PUBLIC_LASTFM_API_KEY`, ~15min) → `npm run resolve-itunes-ids` (resolves an iTunes artistId per distinct artist into the same file, no API key, resumable, takes hours — safe to interrupt and re-run) → `npm run band-genres` (applies thresholds, writes `assets/genres.json`, instant, local, re-runnable while tuning `lib/pool-config.ts`). `npm run report-itunes-resolution` reads iTunes-resolution progress at any point without writing anything.

- Daily Drop: `npm run make-drops` (picks days through 2026-12-31 into `drops/drops.json`; `--dry-run`, `--redo <day> [--slot <slot>]`, `--showcase <day>` then `--choose <day> slot=n …`), `npm run review-drops` (writes `drops/review.html`), `npm run upload-drops` (needs `SUPABASE_SERVICE_KEY`).
- Sound index: `npm run build-sound-index` (every catalog song → Deezer search for its ISRC → ReccoBeats `audio-features?ids=<ISRC>`; writes `assets/sound-index.json` with BPM, key, mode and 8 measures; resumable via the gitignored `scripts/.sound-index-raw.json`; stops itself after `-- --minutes N`, default 50, so run it in chunks; `-- --write-only` rewrites the index from the raw file). Deezer's API terms are non-commercial only; MusicBrainz is the swap if that changes.
- Taste Decoded baselines: `npm run measure-genre-sound -- --from-index` rebuilds `assets/genre-sound.json` from the sound index (the old mode below uploaded previews and is retired). Old: `npm run measure-genre-sound` (30 songs per genre from `assets/catalogs/` through ReccoBeats, one at a time, 3s apart; resumable via `assets/genre-sound-raw.json`; writes `assets/genre-sound.json` only if its sanity check passes; `-- --limit 2` is a dry run on 2 genres).

There is no build/typecheck script configured (`npx tsc --noEmit` can be run directly against `tsconfig.json` if needed). Tests run via Node's built-in runner against the untranspiled `.ts` sources: `node --experimental-strip-types --test lib/discovery.test.ts` (there's no aggregate `npm test` yet — run a file directly).

## Architecture

This is Blindspot, built on Expo Router (v6), with three tabs: **Home**, a Tinder-style swipe discovery feed, **Play**, the Daily Drop and guessing modes, and **Profile**, its listening-data view. A blind-quiz mode also exists in the codebase (`lib/taste-test.ts`) but is not reachable from any current route — see the note at the end of this section before assuming it's live.

- **Routing**: `app/_layout.tsx` is the root `Stack`, wrapping everything in a fixed dark `ThemeProvider` (see Theming below — there is no light/dark switching). It declares the `(tabs)` group (header hidden) plus two modal routes: `modal` ("Liked Tracks") and `export-history` ("Export History"). `unstable_settings.anchor` is `(tabs)`.
- **Tabs**: `app/(tabs)/_layout.tsx` — `Home` (`index.tsx`) and `Profile` (`explore.tsx`), via `HapticTab` and `IconSymbol`.
- **Home tab (`app/(tabs)/index.tsx`)**: the swipe discovery feed. Renders `ListenCard` (`components/home/`, see New Home below) over a queue of `DiscoveryTrack`s maintained by `lib/discovery.ts`'s queue engine (`refillQueue`/`refillQueueWithFallback`). Session state starts on a random genre `Strategy` — `GENRES` from `lib/taste-test.ts` is the only export of that file still imported anywhere — a genre strategy is served by the pool (`lib/pool.ts` `getTracks`) and an artist strategy (steering) by `fetchTracksByArtist`. `fetchTracksByGenre` is no longer on Home's path (see `bugs.md` 2026-10-08: the pool ignores region, and an unseeded genre name falls back to another genre).
  - **New Home (2026-10-08, spec `docs/superpowers/specs/2026-10-08-new-home-design.md`)**: the top card is `ListenCard` (`components/home/listen-card.tsx`). Blind, it draws the song's sound with Skia (`components/print/live-print.tsx`): a recipe from `lib/print-recipe.ts` (triad rings on a circle-of-fifths dial from key/mode, warm hues for major and blue for minor, never violet; density from energy; breathing at the *visual tempo*, BPM folded into 70–140) animated by the playback clock. Mono labels: `PRINT n/50`, the clock, `148 BPM · C♯ MAJOR` only when measured. Tap pauses, double-tap saves. Cards underneath are `StackFace` stills.
  - `ActionRow` (`components/home/action-row.tsx`) spells out the swipes: Skip / New genre / More like this; after a reveal, Save / Details / Next. Buttons call `ListenCard`'s `fling(d, true)` so a tap animates and dispatches exactly like a swipe. Home's `lib/action-lock.ts` lock allows one action at a time (swipes, buttons, Undo; frees itself after 4s); `refillEpochRef` is the one generation token every async result checks.
  - Right = reveal in place + More like this: particles settle (300ms), the cover sharpens in the same frame (400ms, one haptic), the name and listeners + Call it come in; the recipe freezes at commit (`revealRecipeRef`). The next 3 songs come from `nearestBySound` (`lib/pool.ts`, ranked by `lib/sound-neighbors.ts`, bundled catalog + index, no network); the note above the card says why. `DetailsSheet` holds links, Call it, comments and "The sound". On a revealed card left/right/Next move on, down jumps genre. Left = skip (stays blind). Down = `GenreStamp` + a fork in the piece (`pickJumpGenre`, weighted toward genres not yet heard).
  - **The piece** (`lib/piece.ts`, store `hooks/use-art.ts` v3 via `useSyncExternalStore`, migrated from the v2 cover collage): every swipe adds a mark (reveal = the song's print, skip = grey ring, saved = red ring, `branch` forks on genre jumps), 50 per piece; undo survives the 50th-mark rollover. `PieceStrip` under the card, `FlyingPrint` carries the reveal's badge into its slot, `app/art.tsx` shows the piece large (tap a print for its song) and exports a Skia poster (`components/print/poster-canvas.tsx`).
  - **Sound data** (`lib/sound.ts`, `lib/sound-match.ts`, `lib/sound-index.ts`, `lib/sound-lookup.ts` + `lib/sound-lookup-app.ts`, `hooks/use-sound.ts`): the bundled index first, then an AsyncStorage cache, then a live Deezer → ReccoBeats lookup (2 at once, pauses on a 429, never on web: Deezer has no CORS). No preview audio is ever uploaded or downloaded. Missing values stay null; a song without data gets a cover-colored fallback print.
  - **Skia on web**: Skia binds CanvasKit when its module is evaluated, so every file importing `@shopify/react-native-skia` is a `*-canvas.tsx` loaded through `lazySkia` (`components/print/lazy-skia.tsx`) or after `loadSkia()`. The web preview needs `npx setup-skia-web public` once (the 8MB `public/canvaskit.wasm` is gitignored). Chrome caps ~16 WebGL contexts per page. `app/print-lab.tsx` (dev only) shows six sample prints.
  - **Particles with a reason (2026-10-09)**: listening develops them (they gather toward the rings with the furthest point heard, fully formed at 80% of the preview); a drag moves them (right gathers, left scatters and fades, down drops them); `lib/taste-distance.ts` (mean distance to your 3 nearest saves with sound data, at least 5; cuts calibrated on the index) makes far songs restless and labels them CLOSE TO HOME / NEW GROUND / DEEP IN YOUR BLIND SPOT. Each mark stores `heard` (0–1): a close listen draws a crisp print, a quick skip a small dot.
  - **Sort by sound (2026-10-09)**: Tune → Sound has five Low / Any / High switches (`lib/sound-filter.ts`: Pace, Energy, Texture, Mood, Groove; the middle of each range is left out). While any is on, genre refills come from `getTracksBySound` (`lib/pool.ts`, catalog + index, no network); under 3 matches, switches are let go finest-first and the note says "loosened". Remembered in storage through genre jumps and restarts; artist steering ignores it.
  - **Feed loading states (2026-10-09, Prototype 6)**: `runRefill` drives `lib/feed-load.ts` (waiting → slow at 6s, failed offline/empty with attempt count, stopped). With no card, `FeedStatus` (`components/home/feed-status.tsx`) takes the card's place with Cancel (undo back to where you were, or stop), Try again (re-runs the last refill via `lastRefillRef`) and Another genre; a background refill failure shows a tap-to-retry note line. Tune → Test network (`simulate`, Off / Slow 8s / Offline, not saved) wraps only the refill fetcher.
  - **The Edition (2026-10-09)**: every 5 reveals (`lib/edition.ts` addReveal; store `hooks/use-editions.ts`, undo-aware) make a ~32s reel: an intro grid, one scene per song in a rotating family (Flow particles, isometric Terrain, circle-of-fifths Orbit, glass Orb with the cover; `components/edition/edition-canvas.tsx`, lazy Skia), then a lockup of the five prints. Home's note line says "EDITION No. N IS READY"; `app/edition.tsx` (full-screen modal) plays each scene's preview, shows reel-style mono labels (scene number, its own 30fps frame counter, never beats), tap pauses, swipe down or ✕ closes, and the end offers Replay / Share (a Skia still, `edition-poster.tsx`) / Done. Past editions replay from the art screen. Built in Blindspot's own print language; `claude-motion-reel.html` never reached this Mac, so the scenes are self-contained to restyle when it does.
  - The old `CardStack`/`SwipeCard`/`CardFace`/`RevealCard` (`components/discovery/`) are still used by Daily Drop, the Blind Spot Test, Blind Pack and DJ Picks.
  - `TuneSheet` holds the feed controls — preset chips, `SteeringRow` ("more from this artist" / "more like this sound"), and `RegionToggle` — behind one button, so the screen itself is just Undo, the genre pill, the card, Tune and Liked.
  - `GenrePicker` (`components/discovery/genre-picker.tsx`, taxonomy in `genre-taxonomy.ts`) lets the user jump directly to a curated genre, a taxonomy group, or a previously-`Discovered` one (a raw iTunes `primaryGenreName` string outside the curated list).
  - `RegionToggle` (inside `TuneSheet`) switches the iTunes storefront (`Region`: US/MX/ZA — `docs/superpowers/specs/2026-09-05-region-storefront-design.md`).
  - `LikedTracksButton` opens the `modal` route.
  - **Crossfade** (`lib/playback-crossfade.ts`, math in `lib/crossfade.ts`): a left drag fades the next card's song in on a second "peek" player in `PlaybackProvider`; a skip promotes it gaplessly (`promotePeek`), a snap-back eases it out.
  - **Finds News** (`lib/finds-news.ts`, `lib/finds-news-api.ts`, `hooks/use-finds-news.ts`, `components/finds-news-sheet.tsx`): the "While you were gone" strip and sheet — milestones (`lib/milestones.ts`) and new releases for saved artists.
  - **Called Shots** (`lib/called-shots.ts`, `hooks/use-called-shots.ts`, `components/discovery/call-button.tsx`): Call it on the reveal, 3 a week, hits on milestones.
  - The Liked list steers Home through `lib/steer-request.ts` (Home takes the request when it's next focused).
- **Play tab (`app/(tabs)/play.tsx`)**: entry cards for the Daily Drop and two modes. **Daily Drop** (`hooks/use-daily-drop.ts`, `lib/daily-drop.ts`, specs `docs/superpowers/specs/2026-09-29-daily-drop-design.md` + `2026-09-29-play-tab-design.md`): `app/drop-play.tsx` (5 blind cards, down-swipe off) → `app/drop-guess.tsx` (which one has the most listeners?) → `app/drop-results.tsx` (swipe cards ranked fewest→most listeners via `rankByListeners`). Votes/guesses go to Supabase over plain REST (`lib/supabase.ts`, `lib/drop-sync.ts`); drops are made offline by `npm run make-drops` → `review-drops` → `upload-drops`, schema in `supabase/setup.sql`. **Blind Spot Test** (`app/blind-test.tsx`, logic `lib/blind-test.ts`): pick "never" genres → 10 blind songs, half from them → the gap result. **Blind Pack** (`app/pack-send.tsx` → share link → `app/pack.tsx`, logic `lib/blind-pack.ts`): the public website (`https://blindspot.expo.app`, EAS Hosting, `npx expo export -p web --clear && eas deploy --prod`) serves only `/pack` — every other web route shows a landing note, because Last.fm's terms need written approval for public pages using its API. Credits required by iTunes/Last.fm terms live in `components/credits.tsx`. **Modes**: `app/play-spot.tsx` (Spot the Star: which of 4 has 1M+) and `app/play-h2h.tsx` (Head to Head: which of 2 has more), logic in `lib/game-pool.ts`, pool built once from the bundled catalogs by `hooks/use-game-pool.ts`, best streaks in storage.
- **`modal` route (`app/modal.tsx`, "Liked Tracks")**: review liked tracks, add a note to one from the player bar (`NoteSheet`, `setLikedNote`), delete into **Recently deleted** (`app/recently-deleted.tsx`: restore to the old spot or clear for good; pure rules in `lib/saved-songs.ts`, storage in `deleteLikedTracks`/`restoreDeletedTracks`, events via `deleteLikes`/`restoreLikes` in `components/like-button.tsx`), share or export them as a batch (`appendExportBatch`), link to `export-history`. Each row shows the artist's listener count when you found them (the liked track's `artistListeners`) against today's (`hooks/use-listeners-now.ts`, Last.fm `fetchArtistListeners`, cached 12h in storage); a summary card names the best call and how many finds you "called" (at least doubled, `describeGrowth`).
- **`export-history` route (`app/export-history.tsx`)**: past export batches (`loadExportBatches`).
- **Profile tab (`app/(tabs)/explore.tsx`, "Your ears")**: since 2026-10-09 three views behind `ViewSwitch` (`components/you/view-switch.tsx`): **Piece** (default: the Home piece via `PieceView`, Editions, the Called It story), **Discoveries** (count, Tasteform, Decoded, Rewind, Called it, iceberg) and **Insights** (type, tiles, how you listen, range, receipt, Spotify file). Skeleton blocks while loading; a solid status-bar strip. The rest of this entry describes the pieces themselves. It opens on the **Tasteform** (`components/tasteform/`, pure layout in `lib/tasteform.ts`, cover colors from 3×3 iTunes PNGs via `lib/cover-color.ts` + `hooks/use-cover-colors.ts`, breathing pace from each song's energy (ReccoBeats catalog values from the sound index or the live lookup, via `hooks/use-song-feel.ts` and `lib/song-feel-api.ts`; nothing is uploaded); spec `docs/superpowers/specs/2026-09-30-tasteform-design.md`) — saved songs as one shape with Shape/Genre/Listeners/Color/When modes, pinch/double-tap zoom, tap a cover to play it in the pinned `MiniPlayer`. Below it, a few sentences about your blind finds, not a stats dump — how many songs you found blind, the median listener count you found them at, which ones you called, genres you liked blind, and your first find. Built from liked tracks (dates backfilled from swipe history via `withLikedAt`) and `summarizeFinds`. A **Rewind** row under the Tasteform opens `app/rewind.tsx` (full-screen): your finds one day at a time. The length of a horizontal drag picks the step: the previous day with songs, the same date last month, or the same date last year, landing on the closest day with songs when that date has none (`jump`). Sliding up inside a zone locks it into a scrub that stops only on days with songs (`scrubStops`: each song day, or the same date each month or year), with a big readout above the strip. Each strip zone shows its landing date (`zoneLabel`) (pure rules in `lib/rewind.ts`), the DAY · MONTH · YEAR strip is `components/rewind/rewind-strip.tsx`, and the cassette with turning reels is `components/rewind/cassette.tsx`. A Spotify switch in its header imports your Spotify liked songs, plus songs you added to your own playlists, deduplicated by `mergeSaves`, and shows them apart from blind finds. Pure logic is in `lib/spotify.ts`, login and storage in `lib/spotify-api.ts`. Spotify redirects to the web page `app/spotify-callback.tsx` (the second route the public site serves besides `/pack`), and `app/spotify-auth.tsx` swallows the Android return link. Spotify development mode allows 5 accounts, and `SPOTIFY_CLIENT_ID` comes from the user's Spotify developer dashboard. Since 2026-10-03 it's a scroll of stat cards (pure math in `lib/you-stats.ts`; cards and the iceberg, receipt and festival share pictures in `components/you/you-cards.tsx`). The "Your Spotify" cards use only a Spotify file the person imported (`lib/spotify-file.ts`, Exportify CSV/ZIP), never login data, per Spotify's Developer Policy. The same file makes Home's feed skip artists already in it (`lib/known-artists.ts`). Under the Tasteform, the **Decoded** line (Taste Decoded: pure findings in `lib/taste-decoded.ts` against `assets/genre-sound.json`, measuring shared via `lib/song-feel-api.ts`, hook `hooks/use-taste-decoded.ts`, page `app/decoded.tsx`; spec `docs/superpowers/specs/2026-10-02-taste-decoded-design.md`).
- **`lib/discovery.ts`**: the core engine — `DiscoveryTrack`/`SwipeEntry`/`Strategy` types, the iTunes fetch layer (`fetchTracksByGenre`, `fetchTracksByArtist`, `fetchForStrategy`), the queue engine (refill, album-spread, genre-jump selection), and the listener/growth helpers the reveal, Liked list and Profile read (`describeListeners`, `describeGrowth`, `summarizeFinds`). Tested via `lib/discovery.test.ts` (Node's built-in test runner, see Commands above).
- **`lib/discovery-storage.ts`**: all `AsyncStorage` persistence for the discovery feed — swipe history, discovered genres, liked tracks, export batches. Same best-effort convention as the rest of the codebase: a read/write failure falls back to empty rather than throwing.
- **`lib/taste-test.ts`**: mostly vestigial. Its blind-quiz flow (setup → playing → reveal → summary), persistence, and scoring (`isMismatch`) aren't imported anywhere in `app/`. Only `GENRES`, the curated genre list, is still live — reused by the Home tab's genre picker/jump logic and by the pool-steering control's Phase 0 seed script. Treat this file as off-limits by longstanding convention regardless of reachability; just don't assume the rest of this file describes a running feature.
- **Pool-steering control (in progress, 2026-09-14 on)**: a discrete 4-preset control over artist popularity × song rank, replacing — not augmenting — the genre-strategy fetch path above (see `features.md`/`bugs.md`'s 2026-09-14 entries and `docs/superpowers/specs/2026-09-07-taste-space-design.md`'s correction note for how this relates to the earlier, unbuilt "Taste Space" continuous-dial design). `lib/pool-types.ts`, `lib/pool-config.ts`, the three-script Phase 0 pipeline above (dev-only), and `lib/pool.ts` (Phase 1, the runtime data layer Home now uses for genre strategies).
- **Human-only discovery** (`lib/human-check.ts` pure rules, `lib/human-check-api.ts` network + the Tune → "AI-made music" Hide/Show setting, default Hide): artists tagged as AI by Last.fm listeners or MusicBrainz editors are skipped in the Home feed, Similar hops, the games and chart "hear blind"; search and song pages still show them, labeled. The built-in list comes from `npm run scan-ai-artists` → `assets/ai-artists.json`; crowd reports ("Sounds like AI?", 3 phones) live in Supabase (`supabase/ai-reports.sql`). The reveal shows proof of a real person from MusicBrainz (shows, vinyl/CD) — no proof never means AI. Daily Drops are always human-only (`isRealArtist`).
- **Path alias**: `@/*` maps to the project root (`tsconfig.json`), used throughout instead of relative imports.
- **Theming**: `constants/theme.ts` — navy (`#13213f`) as the room, cream text, one red signal (`#e63946`, used for symbols, the heart, streaks and big numbers only — it's 3.8:1 on navy, too low for small text; buttons are cream with navy text). Fonts: Archivo (display), Figtree (text), DM Mono (numbers/labels), loaded in `app/_layout.tsx`; `ThemedText` maps a `fontWeight` to the right Figtree file via `fontFor`. Mode symbols live in `components/emblems.tsx` (react-native-svg, one 64×64 line-and-accent grammar); the bottom bar is custom (`components/tab-bar.tsx`). No emoji or violet in UI; reveal cards take color from blurred album art.
- **Shared audio playback**: `hooks/use-playback.tsx`'s `PlaybackProvider` (wrapping the whole app in `app/_layout.tsx`) and `usePlayback` are the single shared player instance across Home, the liked-tracks modal, and export history — see `docs/superpowers/specs/2026-09-05-shared-audio-player-design.md`.
- **Platform-specific files**: the `.ios.tsx` suffix convention is in use (`components/ui/icon-symbol.ios.tsx`) — Metro picks the right file per platform automatically; add new platform variants the same way rather than branching on `Platform.OS` inside a shared file when the implementations diverge significantly.
- **Icons**: `components/ui/icon-symbol.tsx` wraps SF Symbols on iOS (via `icon-symbol.ios.tsx`) and maps to Material Icons on other platforms — new icon names must be added to the mapping in the non-iOS variant.
- New routes are added simply by creating a file under `app/` (or `app/(tabs)/` for another tab); Expo Router derives the route tree from the file structure, and `experiments.typedRoutes` in `app.json` generates typed route params into `.expo/types/router.d.ts`.
