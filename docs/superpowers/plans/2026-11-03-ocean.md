# The Ocean Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home's sea becomes real water you can swipe up into: 16 places that filter the feed, and an ocean built entirely from what the listener did.

**Architecture:** Everything a person's ocean contains is a pure function of swipe history, Library, sound data and the clock (`lib/ocean-*.ts`, tested in Node). Home and the ocean are one tall sheet joined at the sea line: a drag moves the sheet, Home stays mounted so the song keeps playing, and the scene is a lazily loaded Skia canvas behind the join. Static art and creature sprites are recorded once as `SkPicture`s; one worklet composes them each frame and only runs while the ocean is on screen.

**Tech Stack:** Expo SDK 58, Reanimated 4.7, Gesture Handler 3.3, Skia 2.14 (`createPicture`, `<Picture>`), Node's test runner.

**Spec:** `docs/superpowers/specs/2026-11-02-ocean-design.md`

**Who builds what:** Codex writes the pure libs and first drafts of the art and sheets. Claude writes Home's integration and checks every result by running it. agy reviews the whole branch.

## Global Constraints

- Branch `ocean` on top of `people`, worktree `~/Desktop/prototype0-sdk58`. Nothing is merged or pushed without the user's OK.
- No new native modules (`expo-linear-gradient` is not installed: use SVG or Skia gradients).
- No violet (`isBannedHue`), no emoji, Figtree text, white pill and black button.
- Every file importing `@shopify/react-native-skia` is reached only through `lazySkia`/`loadSkia()`. It must not be imported from `lib/`.
- Home's card, words and buttons don't move. The white stays white.
- Nothing dies, shrinks or fades because you stayed away. No currency, unlocks or decorating.
- Looks are deterministic: the same history always gives the same ocean. Only motion may be random.
- Tests: `node --experimental-strip-types --test lib/<file>.test.ts`. Whole suite: `node --experimental-strip-types --test $(git ls-files '*.test.ts')`. Typecheck: `npx tsc --noEmit`. macOS has no `timeout`.
- Desktop sync creates `" 2"` duplicate files. Never add them.

## Review Focus

- A drag that starts on the card or the action row must never dive; a horizontal swipe or tap on the tab bar must still switch tabs.
- A blind card's song must not be identifiable anywhere under the water: no name, no cover, nothing read by a screen reader, including the "All here" list.
- Rising after the clip ended, or after your songs played under water, must restore the card without losing how long you really listened to it.
- A person with no sound data at all, or no likedAt on old saves, still gets a complete ocean and sentences that make sense.
- Leaving Home mid-drag, backgrounding the app, or Android back during a dive must leave a usable Home, never a half-slid screen.

export type Creature = {
  trackId: number; artist: string; kind: Kind; place: Place; color: string;

  hurried: boolean;       // heard < 0.5

  vivid: number;          // 0.25..1
  likedAt: number | null;
  foundHour: number | null; // local hour, null = always awake
  rare: boolean;
  first: boolean;         // oldest unhurried find

export type CoralPiece = { trackId: number; place: Place; color: string; form: 0 | 1 | 2; size: number; seed: number };
export type SandLife = { rise: number; specks: { color: string; seed: number }[] };
export type PlaceLife = { place: Place; creatures: Creature[]; coral: CoralPiece[]; sand: SandLife; heard: number };
export type OceanLife = { places: Record<string, PlaceLife>; total: number; heardTotal: number; oldest: Creature | null };

export type OceanInput = {
  history: SwipeEntry[];
  liked: DiscoveryTrack[];

export function isAwake(c: Creature, hour: number): boolean;      // 12 hours centered on foundHour
export function whyLines(c: Creature, now: number): string[];
export function portrait(life: OceanLife, now: number): string[];
export function stillBlind(trackId: number, card: { id: number; revealed: boolean } | null): boolean;
export const EXAMPLE_NOTICE: string;
