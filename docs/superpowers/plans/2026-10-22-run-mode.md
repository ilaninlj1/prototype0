# Run Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Run mode in Blindspot that plays blind or saved songs matched to your stride, steers toward an Easy/Steady/Push pace, catches likes without the screen, and ends with a reveal (pace line, hardest-hitting song, Songs and Route tabs).

**Architecture:** Pure, tested modules in `lib/run-*.ts` (step rate and knocks from the accelerometer, pace from GPS, goal pace and steering, song picking, reveal scoring, storage). One hook, `hooks/use-run-session.ts`, wires sensors, GPS, the shared player and a 1 s tick into those modules. Screens: `app/run.tsx` (setup + live), `app/run-reveal.tsx`, `app/runs.tsx`. Dark screens use `DarkColors`.

**Tech Stack:** Expo SDK 57, expo-router, expo-audio (shared `PlaybackProvider` crossfade), expo-sensors `Accelerometer`, expo-location foreground `watchPositionAsync`, expo-keep-awake, expo-haptics, react-native-svg, AsyncStorage.

**Spec:** `docs/superpowers/specs/2026-10-22-run-mode-design.md`

## Global Constraints

- Pace is stored as **seconds per km**, speed as m/s, times in ms. Shown in **min/mile** and **miles** (US class).
- Native modules (`expo-sensors`, `expo-location`, `expo-keep-awake`) are `require`d lazily inside try/catch in one place (`lib/run-native.ts`). A missing module means "Update the app to run", never a crash. App version goes 1.0.3 → **1.0.4**.
- Web and `__DEV__` sims never ship real-looking data into storage, except through the dev-only "Seed a sample run".
- Copy: plain, short, sentence case, no parentheses, no emoji. The lock screen never names a blind song: it says "Blind song #N".
- Tests run with `node --experimental-strip-types --test <file>`. Pure modules import only types from app code, with relative `.ts` imports like the rest of `lib/`.
- Prettier only on new files: `--single-quote --print-width 130 --bracket-same-line --trailing-comma es5`.

## Review Focus

1. **Pocket touches:** a stray touch with no half-second hold must not like, skip or end. Pin it in the live overlay's gate (`lib/run-gate.ts`, Task 6).
2. **GPS dropouts and tunnels:** no fixes for 40 s, then a jump. Pace reads "—" and steering holds, with no lift or ease from stale data. Pinned in Task 3 (`paceOver` null when the window span is under 30 s) and Task 4 (`steerFor` returns `hold` on null).
3. **A tiny pool:** a Blind run after heavy use, or Liked with 3 saves. Picking widens, then falls back, and never returns null while any unplayed candidate exists. Pinned in Task 5.
4. **Very short runs** (under 2 minutes, or 0 songs finished). The reveal still renders, with no hardest-hitting card and no legs likes. Pinned in Task 7.
5. **A locked phone mid-run:** the gap is recorded and excluded from pace and legs scoring. Pinned in Task 7 (`legsLiked` skips songs overlapping a gap).

### Task 2: Step rate and knocks — `lib/run-steps.ts` (Codex)

**Interfaces — Produces:**
```ts
export function detectSteps(samples: AccelSample[]): number[]; // footstrike times (ms)
export function cadence(stepTimes: number[], now: number, windowMs?: number): number | null; // spm over last 10 s; null under 6 steps
export function detectDoubleKnocks(samples: AccelSample[], stepTimes: number[]): number[]; // time of each double knock's 2nd knock
export function createMotionTracker(): { push(s: AccelSample): { knock: boolean }; spm(now: number): number | null; steps(): number[] };
export const WALK_MAX_SPM = 135;
```
Footstrikes: peaks of the low-passed acceleration size above a rolling threshold, at least 250 ms apart. Knocks: a jerk spike (|Δ size| between 10 ms samples) above 0.8 g that settles within 40 ms; a double knock is 2 spikes 120–450 ms apart, neither within 60 ms of a footstrike, with no third spike for 400 ms. The tracker keeps 15 s of samples and reports each double knock once.

- [ ] Tests in `lib/run-steps.test.ts` with synthetic 100 Hz signals (seeded noise ±0.05 g):
  - `running at 2.75 Hz reads 165 ± 3 spm`, `walking at 1.8 Hz reads 108 ± 3`, `standing still reads null`
  - `a double knock on top of running is found once`, `60 s of running alone finds no knocks`, `a triple knock is not a double`, `two knocks 700 ms apart are not a double`
- [ ] Implement; tests pass; commit.

### Task 5: Song picking — `lib/run-songs.ts` + catalog candidates

**Files:** Create `lib/run-songs.ts`, `lib/run-songs.test.ts`; Modify `lib/pool.ts` (append `runCandidates()`).

**Interfaces — Produces:**
```ts
export type RunCandidate = { track: DiscoveryTrack; tempo: number; energy: number; artist: string };
export function beatFor(tempo: number, spm: number): number; // tempo ×0.5/×1/×2, whichever is nearest spm
export function energyBand(steer: Steer): [number, number]; // ease [0, 0.55], lift [0.7, 1], hold [0.45, 0.8]
export function slotIsBlind(mode: SongsMode, index: number): boolean; // mix: index % 3 === 2
export function pickNext(o: { blindPool: RunCandidate[]; liked: RunCandidate[]; mode: SongsMode; index: number; spm: number; steer: Steer; usedIds: Set<number>; usedArtists: Set<string>; rng: () => number }): { cand: RunCandidate; blind: boolean } | null;
// lib/pool.ts
export function runCandidates(): RunCandidate[]; // every catalog song with tempo > 0 in the sound index, one entry per iTunes id, as a DiscoveryTrack (catalogTrack + trackToDiscoveryTrack, preset 'M')
```
Rules: blind fits within 4 %, then 6 %, then 8 %, then nearest beat; one artist per run. Liked: 8 %, then any tempo, repeats of artists allowed, no id twice. Inside the fitting set, songs in the energy band first, else nearest energy; random among the best 5. Mix: a liked slot falls back to blind when no liked song is left; a blind slot falls back to liked when the blind pool is empty.

- [ ] Tests: `fits at half time` (82 BPM fits 164 spm), `widens to 6 % when under 12 fit`, `ease prefers low energy`, `mix plays blind every third`, `mix falls back to blind with no liked songs`, `never repeats an artist in blind`, `returns null only when nothing is left`.

### Task 6: The live session — `lib/run-gate.ts`, `lib/run-sim.ts`, `hooks/use-run-session.ts`

**Interfaces — Produces:**
```ts
// lib/run-gate.ts (pure, tested)
export const HOLD_MS = 500, AWAKE_MS = 5000, JUMP_S = 8;
export function gateAwake(holdStartedAt: number | null, now: number, awakeUntil: number): boolean;
export function seekJump(prevPos: number, pos: number, wallMs: number): 'skip' | 'back' | null; // ≥ JUMP_S within 2.5 s wall
// lib/run-sim.ts
export function createSim(o: { spm: number; speed: number }): { accelAt(t: number): AccelSample; fixAt(t: number): Fix; setEnergy(e: number): void }; // speed responds ±4 % to energy so steering shows
export function sampleRun(now: number, cands: RunCandidate[]): RunRecord; // dev-only seed, simulated: true
// hooks/use-run-session.ts
export type LiveState = { phase: 'idle' | 'running' | 'ended'; elapsedMs: number; distanceM: number; pace: number | null; spm: number | null; beat: number | null; steer: Steer | null; calibrating: boolean; song: RunSong | null; index: number; notice: string | null; simulated: boolean; unsupported: boolean };
export function useRunSession(): { state: LiveState; start(o: { goal: Goal; songs: SongsMode; typedPace: number | null }): Promise<'ok' | 'denied' | 'unsupported'>; like(): void; skip(): void; back(): void; end(): Promise<string | null> /* saved run id */ };
```
Behavior: accelerometer every 10 ms into the motion tracker (knock → `like()` when the profile's `knockOn`); GPS `Accuracy.BestForNavigation`, `timeInterval: 1000`, `distanceInterval: 0`; keep-awake while running; `setAudioModeAsync({ playsInSilentMode: true, shouldPlayInBackground: true, interruptionMode: 'doNotMix' })` and the current player `setActiveForLockScreen(true, { title: 'Blind song #N', artist: 'Blindspot run' }, { showSeekForward: true, showSeekBackward: true })` (real name for liked songs); a 1 s tick records a point every 5 s, steers every 60 s once pace exists, picks and `peekLoad`s the next song, crossfades over the last 2 s with `setMix` then `promotePeek` (falls back to `playPreview`), and checks `seekJump`. Calibration is the first 90 s; `naturalSpm` is the median spm from 30–90 s. AppState background → gap; back to active → notice "Your phone was locked for N minutes, so those minutes aren't in your run." Each finished song → `appendSwipeEntry({ …, action: liked === 'you' ? 'like' : 'skip', source: 'run', listenMs })`. `like()` → `saveLike({ ...track, via: 'run' })` + success haptic. On web, or when `runNative()` is null in `__DEV__`, the sim feeds the same paths and `simulated: true`.

- [ ] `lib/run-gate.test.ts`: `a tap without a hold stays asleep`, `a 500 ms hold wakes for 5 s`, `a 10 s forward jump is a skip`, `a jump after 4 s wall is not`, `normal play is null`.
- [ ] Implement the hook; `tsc` clean; commit.
