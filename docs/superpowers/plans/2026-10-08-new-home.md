# New Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Home around a blind card that shows the song's sound as moving particles, an in-place reveal, three labeled actions, and a piece made of generated prints, all driven by free BPM/key/energy data.

**Architecture:** Pure logic lives in `lib/` (sound data, matching, print recipe, neighbors, piece) with Node tests. A bundled `assets/sound-index.json` (built offline from Deezer ISRC → ReccoBeats) answers catalog songs instantly. A live lookup with an AsyncStorage cache covers the rest. Skia draws prints on the card, the strip and the art screen. Home's screen file sheds its card, reveal and collage code into `components/home/`.

**Tech Stack:** Expo SDK 57, React Native 0.86, Reanimated 4.5, Gesture Handler 2.32, `@shopify/react-native-skia` 2.6.2 (new), expo-image, expo-audio, Node's test runner with `--experimental-strip-types`.

**Spec:** `docs/superpowers/specs/2026-10-08-new-home-design.md`. Read it first; this plan argues from it.

- [ ] **Step 3: Implement** (Codex, from this specification)

`lib/sound.ts`:
- `parseReccoRow`: require finite numbers for `tempo` and all nine of `energy, danceability, acousticness, instrumentalness, speechiness, liveness, valence, loudness`. `key` must be an integer 0–11, otherwise `null`. `mode` must be 0 or 1, otherwise `null`.
- `toIndexRow`: values in `INDEX_FIELDS` order, each rounded with `Math.round(v * 1000) / 1000`, null key/mode → `-1`. `fromIndexRow` reverses it: an array of exactly 11 finite numbers, `-1` key/mode → `null`, otherwise `null` for the whole row.
- `toSongFeel`: `{ energy, valence, tempo, danceability, acousticness, instrumentalness, liveness, speechiness, loudness }`.
- `describeSound` lines, in order:
  1. pace: `tempo < 90` → `Slow`, `< 120` → `Mid-tempo`, otherwise `Fast`, then `· ${Math.round(tempo)} BPM`;
  2. `keyLabel(key, mode)` when not null;
  3. intensity: `energy >= 0.7 && loudness >= -8` → `Loud and dense`; `energy < 0.35` → `Quiet and sparse`; otherwise `Medium energy`;
  4. `Mostly instrumental` when `instrumentalness > 0.5`;
  5. `Lots of talking or rap` when `speechiness > 0.33`;
  6. `Acoustic` when `acousticness > 0.6`.
- `moreLikeLabel` joins with `, `: the lowercase pace word (`slow` / `mid-tempo` / `fast`), then `loud` (same rule as `Loud and dense`) or `quiet` (same rule as `Quiet and sparse`) when either applies, then `keyLabel` when not null.

`lib/sound-match.ts`:
- `cleanTitle`: remove every `(...)` and `[...]` group, cut at the first `' - '`, collapse whitespace, trim.
- `normName`: NFD normalize, strip combining marks (`\p{M}`), lowercase, `&` → ` and `, remove everything but letters, digits and spaces (`[^\p{L}\p{N} ]`), collapse spaces, trim.
- `sameArtist(a, b)`: `normName(a) === normName(b)`.
- `deezerQuery`: `` `${cleanTitle(title)} ${artist}` ``.
- Version words: `live, remix, acoustic, instrumental, karaoke, sped up, slowed`, matched as whole words in `normName(fullTitle)`. A hit is compatible when its set of version words equals ours.
- `pickDeezerMatch`: keep hits that have an `isrc`, have `sameArtist`, and are version-compatible. Return the first whose `normName(cleanTitle(hit.title_short ?? hit.title))` equals ours; otherwise the first where one cleaned title contains the other; otherwise `null`.
- `featuresByIsrc`: for each row with a string `isrc` whose `parseReccoRow` succeeds, set `isrc.toUpperCase()` only if it's not already set.

- [ ] **Step 1: Write the script** (Gemini prompt carries these facts)

```ts
// Builds assets/sound-index.json: BPM, key, mode and 8 other measures for every
// song in assets/catalogs/, matched without touching any audio. Title + artist →
// Deezer search (free, no key, plain query) → ISRC → ReccoBeats audio-features
// (?ids=ISRC,ISRC,…). Progress goes to scripts/.sound-index-raw.json, so a stopped
// run continues where it left off. Stops by itself after --minutes (default 50).
//
//   npm run build-sound-index                  continue, then write the index
//   npm run build-sound-index -- --minutes 5   a short run
//   npm run build-sound-index -- --write-only  just rewrite the index from the raw file

import fs from 'node:fs';
import path from 'node:path';

import { featuresByIsrc, deezerQuery, pickDeezerMatch, type DeezerHit } from '../lib/sound-match.ts';
import { INDEX_FIELDS, toIndexRow, type SoundFeatures } from '../lib/sound.ts';

const ROOT = path.resolve(import.meta.dirname, '..');
const CATALOGS = path.join(ROOT, 'assets/catalogs');
const RAW = path.join(ROOT, 'scripts/.sound-index-raw.json');
const OUT = path.join(ROOT, 'assets/sound-index.json');
const DEEZER_GAP_MS = 250; // 4 a second
const RECCO_GAP_MS = 1_000;
const RECCO_BATCH = 20;
const TIMEOUT_MS = 30_000;

/** itunesTrackId → 'nomatch' | { isrc } (matched, features pending) | { isrc, f } | { isrc, f: null } (no features) */
type RawEntry = 'nomatch' | { isrc: string; f?: SoundFeatures | null };
type Raw = Record<string, RawEntry>;
```

Required behavior (the prompt spells these out):
1. Read every `assets/catalogs/*.json` (`Record<artist, { hits, deepCuts, mixed? }>`; each entry has `title`, `itunesTrackId`). Visit `hits` then `deepCuts`, deduplicated by `itunesTrackId`.
2. For each id not in the raw file, call `https://api.deezer.com/search?limit=10&q=${encodeURIComponent(deezerQuery(title, artist))}`, take `data`, apply `pickDeezerMatch`. Store `'nomatch'` or `{ isrc }`. On a network error or non-200, don't store anything (it's retried next run). Sleep `DEEZER_GAP_MS` between calls.
3. Collect entries with an `isrc` but no `f`, in batches of `RECCO_BATCH`: `GET https://api.reccobeats.com/v1/audio-features?ids=${isrcs.join(',')}`, then `featuresByIsrc(json.content ?? [])`. Store `f` (or `f: null` when that ISRC came back empty). On 429, read `Retry-After` (seconds, default 60), wait it out, and retry the same batch. Sleep `RECCO_GAP_MS` between calls.
4. Every request uses `AbortSignal.timeout(TIMEOUT_MS)`. Save the raw file every 25 Deezer calls and after every ReccoBeats batch (`JSON.stringify(raw)`).
5. Stop starting new work after `--minutes` (default 50). Always finish by writing `OUT`: `{ v: 1, builtAt: new Date().toISOString(), fields: INDEX_FIELDS, songs }` with `songs[id] = toIndexRow(f)` for every entry with features, written as compact JSON.
6. Print coverage: total ids, matched, with features, and per-genre `with features / total`.
7. `--write-only` skips steps 2–3.

Add to `package.json` scripts: `"build-sound-index": "node --experimental-strip-types scripts/build-sound-index.ts"`. Add `scripts/.sound-index-raw.json` to `.gitignore`.

import { featuresByIsrc, deezerQuery, pickDeezerMatch, type DeezerHit } from './sound-match.ts';
import type { SoundRecord } from './sound.ts';

// Live sound lookup for songs outside assets/sound-index.json (artist steering,
// search). Same route as scripts/build-sound-index.ts: Deezer search for the
// ISRC, then ReccoBeats' catalog values. Never touches preview audio.
const DEEZER = 'https://api.deezer.com/search?limit=10&q=';
const RECCO = 'https://api.reccobeats.com/v1/audio-features?ids=';
const AT_ONCE = 2;
const RETRY_UNMATCHED_MS = 14 * 24 * 3600 * 1000;

export type Lookupable = { id: number; trackName?: string; artistName?: string };

type Deps = {
  fetch: typeof fetch;
  read: () => Promise<Record<number, SoundRecord>>;
  write: (all: Record<number, SoundRecord>) => Promise<void>;
  now: () => number;
};

export function createSoundLookup(deps: Deps) {
  let cache: Record<number, SoundRecord> | null = null;
  const inFlight = new Map<number, Promise<SoundRecord | null>>();
  let pausedUntil = 0;
  let running = 0;
  const waiting: (() => void)[] = [];

  const slot = async () => {
    if (running >= AT_ONCE) await new Promise<void>((r) => waiting.push(r));
    running += 1;
  };
  const release = () => {
    running -= 1;
    waiting.shift()?.();
  };

  async function get(url: string): Promise<Response | 'limited' | null> {
    try {
      const res = await deps.fetch(url);
      if (res.status === 429) {
        const wait = Number(res.headers.get('Retry-After')) || 60;
        pausedUntil = deps.now() + wait * 1000;
        return 'limited';
      }
      return res.ok ? res : null;
    } catch {
      return null;
    }
  }

  async function fresh(t: Required<Lookupable>): Promise<SoundRecord | null> {
    const d = await get(DEEZER + encodeURIComponent(deezerQuery(t.trackName, t.artistName)));
    if (d === 'limited' || d === null) return null;
    const hits = ((await d.json()) as { data?: DeezerHit[] }).data ?? [];
    const hit = pickDeezerMatch(t.trackName, t.artistName, hits);
    if (!hit?.isrc) return { status: 'unmatched', at: deps.now() };
    const r = await get(RECCO + encodeURIComponent(hit.isrc));
    if (r === 'limited' || r === null) return null;
    const rows = ((await r.json()) as { content?: unknown[] }).content ?? [];
    const features = featuresByIsrc(rows).get(hit.isrc.toUpperCase());
    return features
      ? { status: 'measured', features, source: 'live', isrc: hit.isrc, at: deps.now() }
      : { status: 'unmatched', at: deps.now() };
  }

  async function lookup(t: Lookupable): Promise<SoundRecord | null> {
    cache ??= await deps.read().catch(() => ({}));
    const hit = cache[t.id];
    if (hit && (hit.status === 'measured' || deps.now() - hit.at < RETRY_UNMATCHED_MS)) return hit;
    if (!t.trackName || !t.artistName || deps.now() < pausedUntil) return null;
    const pending = inFlight.get(t.id);
    if (pending) return pending;
    const job = (async () => {
      await slot();
      try {
        if (deps.now() < pausedUntil) return null;
        const rec = await fresh(t as Required<Lookupable>);
        if (rec) {
          cache![t.id] = rec;
          await deps.write({ ...cache! }).catch(() => {});
        }
        return rec;
      } finally {
        release();
        inFlight.delete(t.id);
      }
    })();
    inFlight.set(t.id, job);
    return job;
  }

  return {
    lookup,
    peek: (id: number) => cache?.[id] ?? null,
    paused: () => deps.now() < pausedUntil,
  };
}

/** A song's sound: the bundled index first, then the phone's cache, then a live lookup. */
export function useSound(track: Lookupable | null | undefined): { record: SoundRecord | null; loading: boolean } {
  const id = track?.id;
  const indexed = id != null ? soundFor(id) : null;
  const [state, setState] = useState<{ id?: number; record: SoundRecord | null; loading: boolean }>({ record: null, loading: false });

  useEffect(() => {
    if (!track || indexed) return;
    let cancelled = false;
    setState({ id: track.id, record: soundLookup.peek(track.id), loading: true });
    soundLookup.lookup(track).then((record) => {
      if (!cancelled) setState({ id: track.id, record, loading: false });
    });
    return () => {
      cancelled = true;
    };
    // The track's id decides what to look up.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [id, !!indexed]);

  if (indexed) return { record: { status: 'measured', features: indexed, source: 'index', at: 0 }, loading: false };
  // A result for a previous card never shows on this one.
  if (state.id !== id) return { record: null, loading: !!track };
  return { record: state.record, loading: state.loading };

  onUpdate?: (feels: Record<number, SongFeel>) => void,
  cancelled: () => boolean = () => false
): Promise<Record<number, SongFeel>> {
  const feels = await loadFeels();

  let changed = 0;
  for (const t of tracks) {
    if (isFullyMeasured(feels[t.id])) continue;
    const indexed = soundFor(t.id);
    if (indexed) {
      feels[t.id] = toSongFeel(indexed);
      changed += 1;
    }
  }

      changed += 1;
      if (!cancelled()) onUpdate?.({ ...feels });
    }
  }
  if (changed) await saveSongFeel(feels);

function draw(r: PrintRecipe, ring: number, size: number, t: number, gather: number) {
  'worklet';
  const p = Skia.Path.Make();
  if (!r.rings[ring]) return p;
  const dot = Math.max(0.7, size / 260);
  for (let i = 0; i < r.particles; i++) {
    if (ringOf(r, i) !== ring) continue;
    const [x, y] = particleAt(r, i, t, gather);
    if (r.texture === 'grain') {
      p.addCircle(x * size, y * size, dot);
    } else {
      const [px, py] = particleAt(r, i, t - (r.stroke === 'dash' ? TRAIL * 0.5 : TRAIL), gather);
      p.moveTo(px * size, py * size);
      p.lineTo(x * size, y * size);
    }
  }
  return p;
}

const STATE_KEY = 'art-state-v3';
const V2_CANVAS = 'art-canvas-v2';
const V2_PIECES = 'art-pieces-v2';

let state: PieceState = { piece: newPiece(1, Date.now()), finished: [] };

async function migrate(): Promise<PieceState | null> {
  const [c, p] = await Promise.all([AsyncStorage.getItem(V2_CANVAS), AsyncStorage.getItem(V2_PIECES)]);
  if (!c && !p) return null;
  const [liked, history] = await Promise.all([loadLikedTracks(), loadSwipeHistory()]);

  const canvas: V2Canvas = c ? JSON.parse(c) : { number: 1, startedAt: Date.now(), marks: [] };
  const pieces: V2Canvas[] = p ? JSON.parse(p) : [];
  return migrateV2(canvas, pieces, (m) => recipeFor(m.trackId, soundFor(m.trackId), null), (id) => {
    const s = songs.get(id);
    return s ? { ...s, artwork: s.artwork || (canvas.marks.concat(...pieces.map((x) => x.marks)).find((m) => m.trackId === id)?.artwork ?? '') } : undefined;
  });
}

function load(): Promise<void> {
  loaded ??= (async () => {
    try {
      const saved = await AsyncStorage.getItem(STATE_KEY);
      if (saved) state = JSON.parse(saved);
      else {
        const migrated = await migrate();
        if (migrated) {
          state = migrated;
          await AsyncStorage.setItem(STATE_KEY, JSON.stringify(state));
        }
      }
    } catch {
      // start fresh
    }
    listeners.forEach((fn) => fn());
  })();
  return loaded;
}

function commit(next: PieceState) {
  if (next === state) return;
  state = next;
  listeners.forEach((fn) => fn());
  AsyncStorage.setItem(STATE_KEY, JSON.stringify(state)).catch(() => {});
}

  commit(out.state);
  return out.finished;
}

export async function saveOnPiece(trackId: number) {
  await load();
  commit(markSaved(state, trackId));
}

/** A genre jump: the next mark starts a new branch. */
export async function forkPiece() {
  await load();

}

export async function undoOnPiece(trackId: number) {

export function useArt(): { piece: Piece; finished: Piece[] } {
  const [, setTick] = useState(0);
  useEffect(() => {
    const fn = () => setTick((n) => n + 1);
    listeners.add(fn);
    load();
    return () => {
      listeners.delete(fn);
    };
  }, []);
  return { piece: state.piece, finished: state.finished };
}

```ts
/**
 * Home's one-action-at-a-time guard: swipes, buttons and Undo all take it
 * first. A lock older than `staleMs` frees itself, so one handler that throws
 * can't freeze the feed.
 */
export function createActionLock(now: () => number = Date.now, staleMs = 4000) {
  let since: number | null = null;
  return {
    take(): boolean {
      if (since != null && now() - since < staleMs) return false;
      since = now();
      return true;
    },
    release() {
      since = null;
    },
    held: () => since != null && now() - since < staleMs,
  };
}
```
